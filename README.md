# alamost.com — Alamo St Advisors

The company site for **Alamo St Advisors**, an independent advisory firm in
Austin, Texas for teams building with AI.

## What it is

A single elegant page: positioning, four service lines (AI strategy, model
evaluation, data pipelines, embedding & search systems), the engagement
approach, about the principal, and contact. No clients are named, no claims
are invented — everything on the page is real.

## Stack

Next.js 14 (app router) + Tailwind. Zero runtime dependencies beyond
Next/React. System font stacks only — no webfonts, no tracking.

## Develop

```bash
npm install
npm run dev
```

## Deploy

Push to `main` — Vercel builds and deploys automatically.
